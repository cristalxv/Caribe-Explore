
# Sistema de diseño — Caribe Explore

## 1. Descripción del proyecto

Caribe Explore es un sitio web para una agencia de viajes. Permitirá a los usuarios conocer destinos, consultar paquetes turísticos y, en una etapa posterior, realizar reservas.

## 2. Paleta de colores

- **Verde principal:** `#166534`. Se utilizará en botones principales, elementos destacados y llamadas a la acción.
- **Azul secundario:** `#075985`. Se utilizará en enlaces, botones secundarios y detalles.
- **Blanco:** se utilizará para fondos y texto sobre colores oscuros.
- **Azul carbón oscuro:** se utilizará para títulos y textos principales.
- **Gris azulado:** se utilizará para descripciones y textos secundarios.
- **Verde claro:** se utilizará como fondo de secciones y áreas destacadas.

Nota: los códigos hexadecimales de los últimos cuatro colores deben verificarse con el documento original del Módulo 3.

## 3. Tipografía

Familia tipográfica: interfaz.

- H1: 40 px, peso 700.
- H2: 32 px, peso 700.
- H3: 24 px, peso 600.
- Texto principal: 16 px, peso 400.
- Texto secundario: 14 px, peso 400.
- Botones: 16 px, peso 600.

## 4. Componentes y estados

### Botón
Fondo verde principal, texto blanco y bordes redondeados.

Estados: normal, hover, presionado y deshabilitado.

### Campo
Fondo blanco, borde gris y texto oscuro.

Estados: normal, focus, error y deshabilitado.

### Tarjeta
Fondo blanco, borde suave y bordes redondeados.

Estados: normal y hover.

### Encabezado
Fondo blanco, logo y menú de navegación.

Estados: normal y elemento activo.

### Pie de página
Fondo oscuro, información y enlaces.

Estado: normal.

## 5. Alcance visual

El diseño se utilizará en la página de presentación de Caribe Explore y en las futuras páginas de destinos, paquetes turísticos y reservas.

## 6. Estado del sistema de diseño

Este documento organiza el sistema de diseño definido para el proyecto en el Módulo 3. Los códigos de los colores complementarios quedan pendientes de verificar con el documento original.
