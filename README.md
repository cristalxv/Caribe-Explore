
# Caribe Explore

## Cliente

Caribe Explore es una agencia de viajes ficticia elegida para el proyecto académico de desarrollo web.

## Descripción del proyecto

El proyecto consiste en desarrollar un sitio web donde los usuarios puedan conocer destinos turísticos, consultar paquetes de viaje y, en una etapa posterior, realizar reservas.

## Alcance del sitio

El sitio se desarrollará progresivamente e incluirá:

- Una página de presentación.
- Una sección de destinos turísticos.
- Una sección de paquetes turísticos.
- Información de contacto.
- Una futura función de reservas.

## Sistema de diseño

La identidad visual utiliza verde principal (`#166534`) y azul secundario (`#075985`), junto con una tipografía y componentes definidos para mantener una apariencia coherente.

La documentación del sistema de diseño se encuentra en `docs/sistema-diseno.md`.

## Estructura del proyecto

- `index.html`: página de presentación.
- `css/estilo.css`: estilos visuales.
- `docs/sistema-diseno.md`: sistema de diseño.
- `img/`: recursos gráficos.
- `js/script.js`: código JavaScript.

## Estado actual

El proyecto se encuentra en su etapa inicial. Se está preparando el repositorio, documentando el sistema de diseño y creando la página de presentación. Las funciones de consulta y reserva se desarrollarán en etapas posteriores.

## Tecnologías

HTML, CSS, JavaScript y Git/GitHub.

## Publicación

El sitio se publicará mediante GitHub Pages cuando la configuración esté terminada.
